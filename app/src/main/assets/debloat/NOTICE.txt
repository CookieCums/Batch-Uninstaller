Bundled snapshot files: aosp.json, carrier.json, google.json, misc.json, oem.json.
These snapshots are included as an offline first-run fallback. AppSieve checks the raw upstream JSON endpoints when updating the database. The data is community-maintained and is not a guarantee that a package is safe to remove.
